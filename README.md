# Next.js starter

A minimal Next.js app in TypeScript with the App Router, Tailwind CSS and ESLint, no database.

- `app/page.tsx`: the home page
- `app/layout.tsx`: the root layout
- `app/globals.css`: global styles and Tailwind CSS
- `next.config.ts`: Next.js configuration

## Run

```sh
npm install
npm run dev
```

Then open http://localhost:3000.
